# Книга рецептов

Документ фиксирует согласованные продуктовые решения в порядке важности. Предложения и варианты, по которым решение ещё не принято, сюда не включаются.

## 1. Назначение

Личное приложение для создания, хранения и использования рецептов. Оно должно помогать придумывать блюда через диалог с LLM и работать с рецептами самостоятельно.

Приложение предназначено для одного пользователя. Поддержка широкой аудитории и высокой нагрузки не требуется. Нужен доступ с разынх устройств, в том числе с телефона.

## 2. Фокус первой версии

Первая версия сосредоточена на самих рецептах:

- Чат с LLM для получения рецептов, подбора идей и обсуждения изменений.
- Личная библиотека сохранённых рецептов.
- Ручное создание рецепта с самостоятельным заполнением его содержимого.
- Ручное редактирование готового рецепта независимо от того, создан он пользователем или моделью.
- Поиск и фильтрация рецептов по времени приготовления и входящим в них продуктам.
- Добавление заметок к рецептам.
- Единый формат рецептов и пересчёт количества ингредиентов по числу порций.

Ручное создание и ручное редактирование — два самостоятельных обязательных сценария. Для них не требуется обращаться к LLM.

## 3. Основные сценарии общения с LLM

### Пользователь знает, какое блюдо хочет приготовить

1. Пользователь запрашивает рецепт, например: «Как приготовить чикен масала?».
2. Модель предлагает рецепт.
3. Пользователь при необходимости просит внести изменения и продолжает обсуждение.

### Пользователь ищет идеи из имеющихся продуктов

1. Пользователь перечисляет продукты, например: «У меня есть курица и яйца. Что можно приготовить?».
2. Модель предлагает несколько вариантов блюд.
3. Пользователь выбирает вариант для дальнейшей работы над рецептом.

## 4. Единый формат рецепта

Рецепты должны иметь понятную и единообразную структуру:

- Название.
- Время приготовления.
- Количество порций.
- Удобно оформленный список ингредиентов с количествами.
- Последовательное описание приготовления по шагам.
- Пользовательские заметки.

Количество ингредиентов должно пересчитываться под выбранное число порций.


## 5. Дополнительные возможности

Желаемые дополнения, без закрепления за конкретной итерацией:

- Кулинарный справочник: например, сколько граммов продукта в столовой ложке и что означает слабый, средний или сильный огонь.
- Калькуляторы перевода единиц измерения, например фунтов в граммы.
